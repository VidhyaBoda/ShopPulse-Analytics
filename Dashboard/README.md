# ShopPulse Analytics — Power BI

The Power BI dashboard contains interactive business intelligence views for
customer shopping behavior.

## Main Analytical Areas

- Revenue KPIs
- Purchase KPIs
- Product/category performance
- Customer segmentation
- Subscription analysis
- Age-group revenue
- Shipping analysis
- Sales distribution
