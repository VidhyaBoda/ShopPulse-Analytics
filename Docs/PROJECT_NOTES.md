# ShopPulse Analytics — Project Notes

## Project Name

ShopPulse Analytics

## Repository Name

ShopPulse-Analytics

## Architecture

The project is intentionally separated into:

- Raw data
- Processed-data documentation
- Python analysis
- SQL database setup
- SQL quality checks
- SQL business questions
- Dashboard-support queries
- Power BI dashboard
- Reports
- Presentation
- Documentation
- Repository assets

## Reproducibility Principle

The Python notebook is the primary source for data preparation.

SQL files are numbered according to execution order.

This makes the project easier to understand, review, reproduce, and extend.

## Security Principle

Database usernames, passwords, API keys, and other credentials must never
be committed to GitHub.
